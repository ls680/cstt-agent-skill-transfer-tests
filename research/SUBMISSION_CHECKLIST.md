# Submission checklist

## Scientific package

- [x] Research question, method, primary endpoint, statistics, and gates frozen
- [x] Failed development mechanisms retained
- [x] Confirmation roster excludes all prior experimental evidence
- [x] Source assignment is outcome-blind and frozen
- [x] All 1,080 confirmation episodes complete
- [x] Three independent run audits pass
- [x] All frozen practical and statistical gates pass
- [x] Claim-evidence matrix updated with final values
- [x] English manuscript compiles without unresolved references or overfull boxes
- [x] Chinese manuscript compiles without unresolved references or overfull boxes
- [x] Release manifest and reproducibility archive verify

## Human inputs required before journal submission

- [x] Replace anonymous author and affiliation fields in the journal-specific version
- [x] Select JAAMAS and apply the current Springer Nature template
- [x] Confirm current scope, data, figure, and AI-disclosure rules
- [x] Select Apache-2.0 for the public repository
- [ ] Create a public archival DOI or anonymous review repository
- [ ] Recheck third-party redistribution terms at release time
- [x] Add funding, conflicts, author contributions, and data statements to the journal-specific version
- [ ] Complete an author-led technical and language review

Artifact completion supports submission readiness, not journal acceptance.
