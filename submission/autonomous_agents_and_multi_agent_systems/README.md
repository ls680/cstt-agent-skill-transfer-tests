# JAAMAS submission package

This directory contains the submission-facing files for *Autonomous Agents and
Multi-Agent Systems*.

The manuscript is a Research article / Manuscript (Regular Paper). JAAMAS
requires the separate `jaamas_information_sheet.pdf`; an incomplete information
sheet can cause return without review.

This is an independent submission package. It contains no manuscript, review
file, or supplementary attachment from another submission. The repository's
research and data records retain the pre-registered zero-overlap audit so that
the confirmation roster can be independently checked.

The public repository and Zenodo DOI are included in the package. Do not submit
until both authors confirm the declarations and the final checklist is complete.
