# Results dictionary

## Development

`development/` contains all pilot and expanded-screen evidence. Failed
mechanisms and superseded partial runs are retained under explicit names. These
records justify the pre-confirmation method decision but are excluded from
confirmatory statistics.

## Confirmation

Each model directory contains:

- `run_spec.json`: model/config revisions and hashes of all consumed scientific
  code and pair inputs;
- `episodes.jsonl`: one complete native record per target and condition,
  including every model decision and environment turn;
- `completion.json`: coverage, process wall time, peak CUDA memory, and the
  SHA-256 digest of the episode file;
- `audit.json`: independent coverage, state-match, native-action,
  candidate-partition, source-assignment, and target-plan-absence checks.

`confirmation/analysis/summary.json` is the canonical statistical result.
`paired_blocks.csv` contains one row per target--model block. TeX tables and
figures are deterministic views generated by `scripts/render_paper_assets.py`.
